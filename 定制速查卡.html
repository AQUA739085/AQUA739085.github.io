三、写文章

约定（2026-10-21 统一）：每篇都写 description（50~120 字，会变成 og/Twitter 摘要）、 category 从 教程 / 日记 / 测试 里选一个、published 用最早成稿的日期 （正文里的"最后更新"不能早于它）。正文从 ## 开始写，不要写 # 大标题——标题由模板渲染，写了会一页两个 H1。

方式一：用命令

pnpm new-post        # 会在 src/content/posts/ 生成一个带 frontmatter 的新文件

方式二：手动建 .md 文件

---
title: "文章标题"
published: 2026-10-21
tags: ["日记", "折腾记录"]
category: "折腾记录"
description: "显示在列表页的摘要"
image: ./images/cover.png     # 封面，可选
pinned: false                  # 置顶
draft: false                   # 草稿，true 则不发布
---

正文从这里开始
字段必填说明
title✅标题
published✅日期，YYYY-MM-DD
tags可选数组：tags: ["a","b"]
category可选单个字符串，不是数组（和 hexo 不一样）
description可选列表页摘要
image可选封面图，./ 开头为相对路径
pinned/draft可选置顶 / 草稿
series可选系列名，配合 seriesOrder

四、图片怎么用（三种方式）

方式适合做法
① 放本地目录
（推荐）		文章配图 图片放 src/content/posts/images/，正文写 ![说明](./images/xx.png)。 Astro 构建时自动压缩、转 webp、生成缩略图。不依赖任何外部 CDN，国内一定加载得出来。
② GitHub + jsDelivr
（图床）		头像、友链头像等需要外链的地方 见下方步骤。零成本，但国内偶尔抽风。
③ 相册页照片墙 一条命令搞定，见下面第五节。本质是把图片复制到 public/gallery/<相册id>/ 再在配置里登记。

jsDelivr 图床搭建步骤

1. GitHub 网页右上角 + → New repository
   名字：images    选 Public（必须公开）    勾 Add a README

2. 上传图片（网页直接拖拽，或用 git）：
   git clone https://github.com/AQUA739085/images.git
   # 把图片放进仓库，然后：
   git add -A && git commit -m "add images" && git push

3. 引用（@main 是分支名，改成 @master 如果你的默认分支是 master）：
   https://cdn.jsdelivr.net/gh/AQUA739085/images@main/图片名.png

4. 文章里用：
   ![说明](https://cdn.jsdelivr.net/gh/AQUA739085/images@main/图片名.png)
jsDelivr 首次缓存要等几分钟才生效；改了同名图片不会立刻更新，建议在文件名里带版本，如 cover-v2.png。 分支名要写对——新建仓库默认是 main，老仓库是 master。

五、建相册：一条命令

pnpm new-album <相册id> "<相册名称>" "<图片目录>" [日期]

例：
pnpm new-album trip-2026 "青岛之行" "D:\Pictures\qingdao"
pnpm new-album trip-2026 "青岛之行" "D:\Pictures\qingdao" 2026-10-03
参数必填说明
相册id✅只能用小写英文、数字、连字符，会同时成为目录名和网址。如 trip-2026
相册名称✅中文随意，有空格要用引号包起来
图片目录✅本机任意文件夹，脚本会把里面的图复制走（不删原图）
日期可选YYYY-MM-DD，不填用今天，用于排序和展示

它会自动完成四件事：

1. 把 jpg/png/webp/avif/gif 复制到 public/gallery/<id>/
2. 在 galleryConfig.ts 的 albums 里插一条
3. 把 siteConfig.ts 的 pages.gallery 打开（原本是关的）
4. 把「相册」加进导航栏「我的」菜单（已有则不重复加）
目录里必须有图片才会执行；<id> 重名会报错防止覆盖。超过 20MB 会提醒你先压图。

封面图怎么指定

放一张名叫 cover.xxx 的图进相册目录即可；没有的话自动用第一张图。
也可以事后在 galleryConfig.ts 那一项里加 cover: "xxx.jpg"、补 description / location / tags， 加 password 还能变成加密相册。
