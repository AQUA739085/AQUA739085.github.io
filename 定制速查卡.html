三、写文章

方式一：用命令

pnpm new-post        # 会在 src/content/posts/ 生成一个带 frontmatter 的新文件

方式二：手动建 .md 文件

---
title: "文章标题"
published: 2026-10-21
tags: ["日记", "折腾记录"]
category: "折腾记录"
description: "显示在列表页的摘要"
image: ./images/cover.png     # 封面，可选
pinned: false                  # 置顶
draft: false                   # 草稿，true 则不发布
---

正文从这里开始
字段必填说明
title✅标题
published✅日期，YYYY-MM-DD
tags可选数组：tags: ["a","b"]
category可选单个字符串，不是数组（和 hexo 不一样）
description可选列表页摘要
image可选封面图，./ 开头为相对路径
pinned/draft可选置顶 / 草稿
series可选系列名，配合 seriesOrder

四、图片怎么用（三种方式）

方式适合做法
① 放本地目录
（推荐）		文章配图 图片放 src/content/posts/images/，正文写 ![说明](./images/xx.png)。 Astro 构建时自动压缩、转 webp、生成缩略图。不依赖任何外部 CDN，国内一定加载得出来。
② GitHub + jsDelivr
（图床）		头像、友链头像等需要外链的地方 见下方步骤。零成本，但国内偶尔抽风。
③ 相册页照片墙 图片放 public/gallery/<相册id>/，然后在 galleryConfig.ts 里加一项描述。

jsDelivr 图床搭建步骤

1. GitHub 网页右上角 + → New repository
   名字：images    选 Public（必须公开）    勾 Add a README

2. 上传图片（网页直接拖拽，或用 git）：
   git clone https://github.com/AQUA739085/images.git
   # 把图片放进仓库，然后：
   git add -A && git commit -m "add images" && git push

3. 引用（@main 是分支名，改成 @master 如果你的默认分支是 master）：
   https://cdn.jsdelivr.net/gh/AQUA739085/images@main/图片名.png

4. 文章里用：
   ![说明](https://cdn.jsdelivr.net/gh/AQUA739085/images@main/图片名.png)
jsDelivr 首次缓存要等几分钟才生效；改了同名图片不会立刻更新，建议在文件名里带版本，如 cover-v2.png。 分支名要写对——新建仓库默认是 main，老仓库是 master。
